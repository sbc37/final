# Paradise Nursery Shopping Application

**Paradise Nursery** is an online plant shop built with React and Redux Toolkit.

## Features

- **Landing page** with a background image, the company name and a "Get Started" button.
- **About Us** section describing the company.
- **Product listing page** with houseplants grouped into three categories (Aromatic, Medicinal and Air Purifying), each showing a thumbnail, name, description and price.
- **Add to Cart** buttons that add the plant, disable themselves once added, and update the cart icon count.
- **Navigation bar** on the product and cart pages with links to Home, Plants and Cart.
- **Shopping cart page** showing each plant's thumbnail, name, unit price and subtotal, with buttons to increase, decrease or delete items, the total cart amount, a Checkout button ("Coming Soon") and a Continue Shopping button.

## Tech stack

- React 18 + Vite
- Redux Toolkit (`createSlice`, `configureStore`) and React Redux

## Run locally

```bash
npm install
npm run dev
```
